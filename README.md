# Harmonysplorer

Browser-based chord progression explorer with 4-voice leading.

**[Try it →](https://oberlin-t.github.io/harmonysplorer)**

## Notation

Jazz convention: `7` = dominant 7th, `maj7` = major 7th, `h` = half-diminished, `o` = diminished.

**Inversions** — `I:1` (3rd in bass), `I:2` (5th / cad. 6/4), `V7:1`, `V7:3`

**Accidentals** — `bVI`, `bVI7`, `#IV`

**Secondary dominants** — `V7/ii`, `V/V`, `V7/bII`

Type any numeral directly in the input box.

## Run locally

Open `index.html` in any browser.
